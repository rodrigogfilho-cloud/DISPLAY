# Estudo de Displays no CSS

Projeto criado para estudar os principais valores da propriedade `display` do CSS e entender seus diferentes casos de uso na construção de layouts.

## 📚 Sobre o projeto

A propriedade `display` define como um elemento HTML será exibido e como ele participa do fluxo do documento.

Neste projeto, cada exemplo demonstra na prática o comportamento de diferentes tipos de `display`, permitindo comparar suas características e entender quando utilizar cada um.

## 🎯 Objetivos

- Entender o funcionamento da propriedade `display`.
- Praticar os principais valores utilizados no CSS.
- Comparar o comportamento dos elementos em diferentes layouts.
- Aprender através de exemplos visuais e práticos.

## 🧩 Displays estudados

- `block` — ocupa toda a largura disponível e inicia uma nova linha.
- `inline` — ocupa apenas o espaço necessário e permanece na mesma linha.
- `inline-block` — combina características de `inline` e `block`.
- `flex` — facilita a criação de layouts unidimensionais.
- `grid` — permite criar layouts baseados em linhas e colunas.
- `none` — remove o elemento da renderização da página.
